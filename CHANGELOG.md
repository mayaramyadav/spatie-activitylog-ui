# Changelog

All notable changes to this project are documented in this file.

## [0.3.0] - 2026-04-03

### Added

- Added configurable logo and favicon handling with sensible default asset paths.
- Added fallback behavior when published logo or favicon assets are unavailable.
- Added support for an “All time” analytics period.
- Added compatibility coverage for normalized activity payloads.

### Changed

- Improved dashboard data loading and consolidated dashboard statistics handling.
- Improved analytics date-range resolution and filter management.
- Normalized event types and subject types consistently across the activity log UI.
- Updated activity properties handling to align with Spatie Activitylog data.
- Improved authorization and activity log handling.
- Updated Laravel and PHP compatibility documentation and package metadata.
- Refined dashboard interactions, event listeners, and visual presentation.
- Updated PHPUnit configuration and expanded test coverage.

## [0.2.0]

- Refreshed the UI with a modern Zinc-based design system.

## [0.1.0]

- Initial documented release.
